# Engine board

Goal: the engine clearly separated, complete and legal, agnostic of humans
and bots, behind an API convenient for platforms, agents and developers
(roadmap: architecture, objective C). Skill: `engine-review` on every
engine commit. Docs: `docs/engine.md`, `docs/protocol.md` (the contract,
semver), `crates/api` (`schema.json`, `openapi.json`, `protocol.ts`),
`docs/online-plan.md` (the architecture as built), DESIGN §4, §9. Covers
the engine's architecture, `api`, `host`, `text`, `server`, performance,
the rulebook mechanisms no card carries (card definitions and readings
are the cards board's), and the harness (CLAUDE.md, the `intake`, `ship`
and `upkeep` skills, `docs/index.md`).

A shrinking list (CLAUDE.md "Harness"): one line an ask, its done-condition
and the docs it changes; done is deleted; order is priority; the only
state is `[doing: <session>]`. Order: what the community beta's games meet
first (the server's records and restarts, a rule players hit),
then the protocol leaks the Succubus Club fork works around, then the API
for outside platforms and contributors, then the training layer split,
the remaining mechanisms, the review leftovers, the harness.

- **A failed block attempt is the blocker declining** (the owner's playtest, 2026-10-17, via Z-play; the owner agrees with the reading): when the acting minion plays stealth against a block attempt, the impulse goes round the whole table (anyone may add intercept); if the attempt still falls short it fails, and that is the blocker declining (rulebook 2024 "If a block attempt fails, either another attempt is made or the defending Methuselah declares that they will not make any further attempts to block"; rules-qa 48.6, a failed attempt not offered again unchanged): no acting-impulse step between the failure and the decline; prey then predator unchanged, the acting impulse after every decline (Change of Target, G00106). Done when a test plays stealth into an attempt, the table passes, and the next decision is the next would-be blocker's or the action's, never the acting seat's in between, the goldens re-blessed with their moves explained. Docs: rules-qa (a new item, the owner's ruling), rules-digest, engine.md (blocks), human-play 2.31 if it states the re-ask.
- **Opportunities off: no stealth without an attempt to beat, no intercept outside one's block moment** (the owner's playtest, 2026-10-17, via Z-play): with the opportunities off, a stealth gain is hidden while no block attempt is under way (Gathii: "really an uninteresting cornercase possibility"), and On the Qui Vive and its kind (intercept for a would-be blocker) shown only in that seat's own block moment, not before or after it ("really misleading, even though technically correct"). Done when host tests hide both with the opportunities off and show them on. Docs: protocol.md §8 (what the opportunities hide).

A seed of 53 bits (exact as a JSON number), the server's: the api type, the engine's rng seeding, records, the py crate, training — a protocol major (2.0.0). Ask the owner whether and when, 2026-10-16. Done when a server seed exceeds 2^32 and a record of one replays. Docs: protocol.md (§14, the spec), DESIGN (replay), the training line told.
