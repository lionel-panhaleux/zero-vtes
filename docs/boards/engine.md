# Engine board

Goal: the engine clearly separated, complete and legal, agnostic of humans
and bots, behind an API convenient for platforms, agents and developers
(roadmap: architecture, objective C). Skill: `engine-review` on every
engine commit. Docs: `docs/engine.md`, `docs/protocol.md` (the contract,
semver), `crates/api` (`schema.json`, `openapi.json`, `protocol.ts`),
`docs/online-plan.md` (the architecture as built), DESIGN §4, §9. Covers
the engine's architecture, `api`, `host`, `text`, `server`, performance,
the rulebook mechanisms no card carries (card definitions and readings
are the cards board's), and the harness (CLAUDE.md, the `intake`, `ship`
and `upkeep` skills, `docs/index.md`).

A shrinking list (CLAUDE.md "Harness"): one line an ask, its done-condition
and the docs it changes; done is deleted; order is priority; the only
state is `[doing: <session>]`. Order: what the community beta's games meet
first (the server's records and restarts, a rule players hit, feedback),
then the protocol leaks the Succubus Club fork works around, then the API
for outside platforms and contributors, then the training layer split,
the remaining mechanisms, the review leftovers, the harness.

- **Games a redeploy left open, ended**: at startup the server ends the games its store lists as going (`server_restart`, recorded), so `/admin/games` and `fetch_games.py`'s cursor stop waiting on them (six such on 2026-10-14, 0 to 134 entries). Done when a server test starts on a store holding a going game and finds it ended `server_restart`. Docs: protocol.md (the end reason and the admin listing).
- **Feedback intake**: a `feedback {text}` command (a minor protocol version) stored with the game's entries at its decision number; `/admin/feedback` lists them for the `intake` skill. Done when a server test sends feedback mid-game and reads it back from `/admin/feedback` at its decision. Docs: protocol.md, `schema.json`, `openapi.json`, `protocol.ts`.
- **Diablerie takes the equipment**: the diablerist may take any equipment on the victim (rulebook, diablerie step 2) through an `Interrupt`; today it burns with the victim. Done when a test diablerizes an equipped vampire and the chosen equipment moves to the diablerist. Docs: engine.md (diablerie); the training line told (a new interrupt).
- **Records complete**: `BotRecord` carries each network bot's nudges and the record its turn count, so `games_report.py` stops replaying records for the turns. Done when a recorded game holds both and the report reads them without replaying. Docs: protocol.md (the record), `data/records/README.md`.
- **Demand for cards counted**: the server counts the card ids `SpecError::Unsupported` refusals name (ids and counts only, no player data) at `/admin/unsupported`, for the cards board's round choice. Done when a server test refuses a deck and reads its ids counted. Docs: protocol.md (admin).
- **Ability labels as data**: an option carries its ability's label (the printed line or an effect summary), so a client names the "Which ability ?" step without the English text's tail (null with `text` off). Done when the option carries it, a host test reads it, and sc.md's boundary leak 1 is gone. Docs: protocol.md, the api schema files, sc.md.
- **Who uses an ability, said**: an explicit user (the Methuselah or the minion) on the option instead of an absent `actor` read as "your Methuselah" (War Ghoul). Done when the option carries it, a host test reads it, and sc.md's boundary leak 2 is gone. Docs: protocol.md, the api schema files, sc.md.
- **A decision's reason in data**: why options are missing (the forced hunt first, rules-qa 17.2), so the fork stops inferring it from the minion phase with no `pass`. Done when the decision carries it, a host test reads it, and sc.md's boundary leak 3 is gone. Docs: protocol.md, the api schema files, sc.md.
- **Markers and names in data**: a marker's kind and count, its name on request; minions of one name told apart in the view (the `nth` the text crate's `Names::numbered` computes). Done when the view carries both, a host test reads them, and sc.md's boundary leak 4 is gone. Docs: protocol.md, the api schema files, sc.md.
- **Diablerie of an older vampire, the master Discipline**: its controller may fetch a master Discipline card (library, ash heap or hand) onto the diablerist, the library shuffled or the hand drawn up (advanced rules 4; eleven such cards in the pool). Done when a test diablerizes an older vampire and fetches one from each place. Docs: engine.md (diablerie).
- **The repository open to outsiders**: public since 2026-10-14 (MIT); left: a README for outsiders, CONTRIBUTING (CLAUDE.md and the skills as the contributor's guide), a secrets audit of the history, the server binary as a GitHub release asset (online-plan B7; a release on the owner's word). Done when README and CONTRIBUTING are in, the audit's result is in its commit, and `deploy/` can fetch the release. Docs: README, CONTRIBUTING, online-plan.md B7.
- **Easy to plug in**: protocol §2's minimal client as a runnable Python example over the WebSocket, a CHANGELOG of every `PROTOCOL_VERSION`, a schema-diff check failing a removed or renamed field unless the major moves. Done when the example plays a game against a local server in a check, the CHANGELOG lists every version, and the check fails a renamed field. Docs: protocol.md §2, §14, CHANGELOG.
- **A game survives a restart**: rebuilt from its record at server start (replayed to its last decision), so a redeploy loses no game. Done when a server test restarts mid-game and the seat rejoins at the same decision. Docs: protocol.md, sc.md traps ("no resume").
- **Bot profiles by name in `policy`**: style, weights, temperature and nudges implementing `host`'s `Bots`; the shells stop implementing it. Done when the server and the CLI shells name a profile and hold no `Bots` impl. Docs: online-plan.md A4, protocol.md (profiles).
- **Narration left**: a card canceled told; what a card did, as typed events. Done when both are events with renderer tests. Docs: protocol.md (events).
- **Renderer left**: markers' and strikes' text from data (an oracle each first); the purposes no sweep reaches (`text/src/option.rs` `asked`, declined) rendered. Done when both read data and a test renders every purpose. Docs: none (the text crate).
- **Events as a complete delta stream**: view N plus its events is view N+1; views on decisions only. Done when a host test applies the events to each view over the key sweep's games and gets the next. Docs: protocol.md (events, views).
- **`zvtes-env`, step 1**: `bots::does` out of `bots.rs` into a neutral engine module (`politics.rs` uses it). Done when `bots.rs` holds no rules helper `politics.rs` reads. Docs: engine.md (layout).
- **`zvtes-env`, step 2**: `obs.rs` (with `encode_critic`), `habits.rs` and `bots.rs` into `crates/env` over `engine`; `policy` and `py` on it, `host` for the scripted bots; `agent.rs` and elision stay; the training line told before it merges. Done when the engine crate holds none of them and every check is green. Docs: engine.md, DESIGN §5, the training skill.
- **Definitions exported as data**: every card's definition (modes, requirements, effects, windows; the window matrix) as documented JSON with a schema, generated and `--check`ed. Done when the export and its `--check` are in the CLAUDE.md checks. Docs: engine.md, CLAUDE.md checks.
- **Tournament withdrawal**: the unlock-phase decision, 0.5 VP (rules-digest K41). Done when a test withdraws and scores it. Docs: engine.md, DESIGN §11.3 (mechanisms missing).
- **Paths**: the influence-phase "burn 1 blood to follow a path" for a Sabbat vampire following none (Hartmut Stover, Styles Margs), told to the training line for the observation. Done when a test follows a path and the training board has its observation line. Docs: engine.md, DESIGN §11.3.
- **Immunity to damage from a source**: the mechanism DESIGN §11.3 lists missing. Done when the first pool card needing it is defined with its test, or the line moves to the cards board with that card. Docs: engine.md, DESIGN §11.3.
- **Performance baseline**: an example timing a random 4-seat game and decisions a second against DESIGN §9's targets. Done when the example is in and its numbers are in DESIGN §9. Docs: DESIGN §9.
- **`host/src/effects.rs` exhaustive**: its `_ => {}` becomes a match on `Effect::family()`, `Family::Marker` the only silent arm, so a new player-visible effect cannot go unmapped. Done when adding an unmapped family fails to compile. Docs: engine.md ("What is enforced").
- **The review's unchecked points**: abilities' targets re-validated at resolution (play vs ability); the `ChosenController` branch's `requires`. Done when each is a test or a fix. Docs: engine.md if a mechanism changes.
- **Deep sweeps on a schedule**: `FUZZ_SEEDS` and `HOST_SEEDS` sweeps weekly at `main`'s tip from a pilot session (as the harvest), a panic or a key collision through `intake`. Done when the schedule runs and its first result is triaged. Docs: DESIGN §7.2, the upkeep skill.

Done when both fields are gone and the goldens moved in hashes only. Docs: engine.md (timed state).
