# zero-vtes

A rules-enforcing [VTES](https://www.vekn.net) (Vampire: The Eternal Struggle)
engine in Rust, and a self-play deep-RL agent for the V5 card pool.
[`DESIGN.md`](DESIGN.md) records the architecture and the current state.
